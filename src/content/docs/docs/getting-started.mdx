## What you need

- **Your own copy of the game** on disc, saved as a disc image. [Supported versions](../supported-versions/) tells you
  which disc works, and [Dumping your disc](../dumping-your-disc/) shows how to make the image.
- **A Mac with Apple Silicon.** It's the only system ReRAC is tested on so far. There's a Windows build too, but
  nobody has tried it yet. Linux is planned.
- **About 4.5 GB of free space** for the game data.

## Install and play

<Steps>

1. **Install the ReRAC Launcher.** Download it from the [home page](../../#download). It isn't signed by Apple yet, so
   macOS stops it the first time you open it: go to **System Settings → Privacy & Security** and choose
   **Open Anyway**.

2. **Choose a version of ReRAC.** Open **Settings → Version Management → Official**, click the download arrow next to
   the newest version, then **Set active**.

3. **Add the game.** Select **Ratchet & Clank** in the sidebar, choose **Install via ISO** and pick your disc image.
   The launcher checks the disc and copies what it needs.

4. **Press Play.**

</Steps>

You only add the game once. After that, just open the launcher and press **Play**.

If something goes wrong, see [Troubleshooting](../troubleshooting/). The [controls](../controls/) page shows which key
does what.
