## What you need

- **Your own disc.** A legally obtained PlayStation 2 disc of Ratchet & Clank (2002), **NTSC-U, SCUS-97199,
  version 1.00**, as a disc image (`.iso`). See [Supported game versions](../supported-versions/) and
  [Dumping your own disc](../dumping-your-disc/).
- **A computer.** macOS on Apple Silicon is the development platform and the only one tested so far. Windows and Linux
  are planned but untested.
- **Disk space.** About 4.5 GB for the extracted game data.

ReRAC contains no game assets and no copy of the game's code. Everything the game needs comes from your disc image.

## Install and play

<Steps>

1. **Download the ReRAC Launcher** for your system from the [home page](../../#download), and install it.

2. **Add a game version.** Official versions will be downloadable from **Settings → Version Management → Official**
   once they are published. Pick one and **Set active**.

3. **Install the game data.** Select **Ratchet & Clank** in the sidebar, choose **Install via ISO**, and pick the
   image of your disc. The active version's extractor checks the disc, copies the data (about 4.5 GB) and prepares
   it.

4. **Play.** The launcher starts the game with the extracted data and shows *Running…* until it exits.

</Steps>

The extraction happens once. The engine never reads your disc image again; it reads only the data folder the
extractor wrote.
